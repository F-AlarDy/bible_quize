ควิซพระคัมภีร์ ผจญภัย - วิธีติดตั้งเกม
=====================================

ไฟล์ในชุดนี้
- index.html             ตัวเกมทั้งหมด
- manifest.webmanifest   ข้อมูลแอป (ชื่อ ไอคอน สี) สำหรับติดตั้งบนมือถือ
- sw.js                  ทำให้เกมเล่นได้แม้ไม่มีอินเทอร์เน็ต หลังเปิดครั้งแรก
- icons/                 ไอคอนแอป

แบบที่ 1: เล่นทันทีบนคอมพิวเตอร์
- แตกไฟล์ zip แล้วดับเบิลคลิก index.html
- เล่นได้ครบทุกด่าน คะแนนเก็บไว้ในเบราว์เซอร์ของเครื่องนั้น
- แบบนี้ยังติดตั้งเป็นแอปบนหน้าจอโทรศัพท์ไม่ได้ ต้องใช้แบบที่ 2

แบบที่ 2: ขึ้นเว็บแล้วติดตั้งเป็นแอปบนมือถือ (แนะนำ)
1. อัปโหลดทั้งโฟลเดอร์ขึ้นเว็บโฮสติ้งที่เป็น https เช่น Netlify Drop,
   GitHub Pages, Cloudflare Pages หรือเว็บของคริสตจักร
   (Netlify Drop: ลากโฟลเดอร์ไปวางที่ app.netlify.com/drop ได้เลย)
2. ส่งลิงก์ให้ผู้เล่นเปิดในโทรศัพท์
3. ติดตั้งลงหน้าจอ
   - iPhone (Safari): กดปุ่มแชร์ แล้วเลือก "เพิ่มไปยังหน้าจอโฮม"
   - Android (Chrome): กดเมนูสามจุด แล้วเลือก "ติดตั้งแอป" หรือ "เพิ่มลงในหน้าจอหลัก"
4. หลังเปิดครั้งแรก เกมจะเล่นได้แม้ไม่มีอินเทอร์เน็ต

หมายเหตุ
- กระดานอันดับในชุดนี้นับเฉพาะผู้เล่นบนเครื่องเดียวกัน
  กระดานอันดับออนไลน์ใช้ได้เฉพาะเวอร์ชันที่เปิดผ่านลิงก์ใน Claude
- ถ้าไม่มีอินเทอร์เน็ตตั้งแต่ครั้งแรก ตัวอักษรจะใช้ฟอนต์ไทยของเครื่องแทน
- แก้ไขหรือเพิ่มคำถามได้ในไฟล์ index.html ที่ส่วน const LEVELS
  แต่ละข้อมี q (คำถาม) a (คำตอบที่ถูก) w (ตัวเลือกผิด 3 ข้อ) r (ข้ออ้างอิง)
- เมื่อแก้ไฟล์แล้วขึ้นเว็บใหม่ ให้เปลี่ยนเลข bible-quiz-v1 ใน sw.js เป็น v2
  ผู้เล่นจะได้รับเวอร์ชันใหม่
